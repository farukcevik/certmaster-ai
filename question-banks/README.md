# Local question banks

Question-bank content is intentionally excluded from the public repository.

To run the Google Cloud Professional Data Engineer bank integration tests or package an authorized local bank, place the normalized file here:

```text
question-banks/GCP_PDE_349_questions.json
```

Related extracted images belong under `question-banks/assets/`. Both paths are ignored by Git. You may also import an authorized PDF, JSON, or CSV bank through the application's local import screen.
